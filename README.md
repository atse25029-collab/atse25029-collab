## 📁 Featured Hosted Projects

### 📊 FinTrack — Minimalist Personal Finance & Expense Tracker PWA
A minimalist, high-contrast monochrome Progressive Web App (PWA) built for daily financial tracking with real-time cloud synchronization and multimodal AI intelligence.
* **Architecture:** Offline-first PWA powered by Next.js 15 (App Router), React 19, and Supabase Realtime for instant background data sync across devices.
* **Dual-Wallet Ledger:** Implements a strict separation between physical cash ("Money in Hand") and digital bank funds ("Money in Account") with live balance recalculation.
* **Multimodal AI Vision:** Integrates Google Gemini AI to parse raw receipt images, auto-extract merchants and line items, and categorize expenses without manual entry.
* **Links:** [Live Demo](https://fintrack-liart-ten.vercel.app) • [GitHub Repository](https://github.com/atse25029-collab/Fintrack)

### 🎬 CinemaSync — Synchronized Movie Co-Watching & WebRTC Platform
A high-performance, low-latency synchronized media player enabling real-time movie co-watching with integrated peer-to-peer audio, video, and lobby text chat.
* **Sub-Second Sync:** Coordinated playback state machine using Socket.io with automated heartbeat drift correction to resync buffering or lagging viewers.
* **Peer-to-Peer Mesh:** Overlays real-time camera and mic streams directly onto the video canvas using native WebRTC peer connections.
* **Streaming Engine:** Supports sequential torrent chunk streaming via WebTorrent and on-the-fly cross-platform transcoding with FFmpeg for unsupported formats.
* **Links:** [Live Demo](https://cinemasync-bay.vercel.app) • [GitHub Repository](https://github.com/atse25029-collab/CinemaSync-)

### 🌉 CareBridge — On-Demand Caregiver & Companion PWA
A mobile-first Progressive Web App designed to connect families with verified local temporary caregivers and companions on an hourly basis, localized for Chennai.
* **Mobile-First UX:** Engineered with an interactive smartphone bezel mockup on desktop viewports, complete with dynamic status bar and responsive layout.
* **Booking Workflow:** Multi-step caregiver matching flow, automated hourly wage calculation, and instant booking state management built with React 19 and Tailwind CSS 4.
* **Performance:** High-speed bundling with Vite 6 and installable PWA service workers for offline availability.
* **Links:** [Live Demo](https://carebridge-steel.vercel.app) • [GitHub Repository](https://github.com/atse25029-collab/carebridge)

### 💳 LedgerFlow — Customer Dues & Credit Tracker
A high-fidelity, Obsidian-themed dark-mode financial application engineered to manage cash flow metrics, log customer transactions, and automate debt settlements.
* **Architecture:** 100% serverless hosting on Vercel with an Express API backend running as serverless functions connected to a Supabase PostgreSQL database.
* **FIFO Reconciliation:** Automated First-In, First-Out reconciliation engine on the backend to isolate partial debt repayments safely under atomic SQL transactions.
* **Data Pipelines:** Resilient CSV bulk importing, automated data sanitization algorithms, and custom SVG dynamic charts for financial metric visualization.
* **Links:** [Live Demo](https://ledger-flow-drab-phi.vercel.app) • [GitHub Repository](https://github.com/atse25029-collab/Ledger-Flow)
